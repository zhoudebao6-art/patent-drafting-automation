# 专利撰写自动化

v5.0通用提速：新批次一次冻结规则与工具，各阶段只读一份原文清单；使用公共Word生成器完成重复排版、来源对象导入和客观台账，结构预检结果直接复用。默认4路滚动补位，GPT-6.1-sol/high撰写，GPT-6-astra/high复查、修正及独立重验。保留人工定稿格式、每项至少3处合法所述、源公式及图序、黑字净稿和全部最终页面验收。业务规则版本v17，共54条。每案通过后立即交付到桌面同一批次文件夹根目录，内部case/attempt独立隔离。

## 使用

```text
请使用 $patent-drafting-automation，并行处理“D:\待撰写项目”中的技术项目优化书，按可用名额持续补位，每案独立复查和修改，每案Word复查通过后立即直接放到桌面同一批次文件夹根目录，不按项目建子文件夹，不等全部项目完成。
```

每完成并验收通过一案，总控立即交付并提供文件链接；后续成稿直接追加到同一目录根部。最终目录内直接排列“项目甲.docx”“项目乙.docx”等成稿。审阅台账、中间稿及待处理说明留在工作目录。不同项目可以同时处于撰写、复查、修正阶段，不再等待前一项目全部验收。每案内部保持有序且只允许一个活跃阶段；独立case/attempt目录和哈希绑定防止错案、错稿、旧回执混用。

默认目标4个worker、最多8个在制项目。新批次优先使用[多CLI执行池](references/cli-workers.md)，实际启动独立Codex进程并显式指定模型/high；真实容量受账户及机器资源限制。没有CLI时使用实际可用子代理，只有1个时如实顺序执行。总控通过技能启动，不是定时任务；指定模型不可用时不虚构结果、不静默降级。
