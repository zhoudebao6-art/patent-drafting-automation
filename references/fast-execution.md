# 通用精简执行

主线为来源准备→初稿→独立复查→必要修改后独立重验→逐案交付。当前采用6初稿、3复查、3修改池，draft为Sol/high，review/revise为Sol/xhigh，实际容量显式提供；配置不代表已测吞吐。本页集中维护机械执行契约，写作规则见冻结阶段包，历史演进见CHANGELOG。

## 新批次一次准备

`worker_preparation=frozen_stage_packet_v1`由parallel_batch.py init一次冻结规则、规范、运行脚本及必要资产，保存SHA和规则/策略身份；历史规则备份和测试脚本不随批复制。来源正文仍按案隔离。freeze只编译一次公共内容，再组合各阶段模型/职责，不跨调用缓存验证结果。

`execution_optimization=lean_execution_v24`保留worker规则的instruction/check/exceptions/scope/section/level/origin原文；仅已知纯主控global规则放worker-controller.md，未知或project规则仍进worker清单。完整active集合只冻结一份rules.active.json，evidence保留在rules.json，覆盖记录绑定全部ID及路由。worker-standard及五份完整原规范由覆盖文件绑定SHA，变更先独立审语义再刷新，过期覆盖不能编译；项目证据契约完整提供。

worker按prepared.pipeline.stage_read_parts顺序读各不超过7000字符的块一次，其拼接须等于stage_guide；截断只补未读范围，不再整读相同JSON或规范。math_guide按公式/附图场景路由：仅有图不加载公式资料，公式图片仍属公式，不能据零OMML判断无公式。条件索引触发时读取完整原节，宿主及documents技能要求保留。非lean旧批次继续使用原全文包。

来源inspection和mapper SHA共同绑定本案source-navigation，由manifest封存后各阶段只读复用，不写回提取cache。来源提取缓存以源SHA和提取器哈希为身份，同名异内容不能复用；复查仍据待审范围核原材料及完整OMML。完整对象、段落和定位用evidence_query按ID或不重叠页读取；技术推算仍由模型据源完成。队列/CLI自动使用本批冻结脚本，绑定与收稿核快照完整性，安装新版本不改在途快照。

## 一次生成与审改

模型核定来源、技术内容、权项及对象身份，再按[公共生成器](authoring-toolkit.md)提交内容。源OMML/图按来源导入，工具不支持的结构走既有保真路径，不展平或丢失。生成器从保存后的实际DOCX读回，调用inspect_docx一次；其有效inspection-cache直接交接，自行生成才预检一次。回执用实际output路径及SHA，客观对象表不提供语义通过结论。用词、名称和版式等现有门禁仍在同次提取/封存证据中执行，不另读DOCX或加模型。

初稿先处理已知问题，不模拟第二轮独立审查；review只读集中列findings，revise修关联内容后交新review会话，不无理由重写全文。内容稳定才渲染。Word字节未变且render_docx_checked.py --verify通过时，复用同案PDF和全部PNG；任何修订改变DOCX后重新渲染。当前六项及全部页须由本轮实查和有效继承完整覆盖；修改影响范围重验，缓存本身不代表通过。历史人工稿只作格式/话术参考，最新用户规则优先，旧空格、截短符号或转置排法不回灌。

段落位移复用只匹配同部件同容器、唯一且完全相同XML、相对顺序不变的已过内容；跨单元格/文本框移动、重复歧义、调序或全局结构改变保守失效。摘要给连续范围，不抄全量哈希。仅可继承已有审阅且与当前渲染一致的页面；其他页实际查看。

## 收稿与交付

worker退出前使用[回执工具](worker-receipt.md)核实际job/dispatch/产物身份并提交一次决定，工具不补passed。新策略修改者返回complete，之后由独立review重验；旧冻结复查内小修才由review返回revised。未改稿pass后主控直接交付，不加格式复查模型、不重渲染同字节稿或逐案编验收/打包脚本。

各验证边界只复用本次已核准对象，不重复打开同一JSON来比对或解析：异步准备提交消费verify_prepared返回的handoff；输出契约消费其input_report；增量计划和回执用同一份原始字节核SHA及解析，保留路径、上下文和身份检查。snapshot、inspection及rules快照沿用相同单读约定。单次增量validate的历史链由有页page_map或无页分支核一次。下一次验证重新读取，不跨事务缓存通过、不合并锁内外manifest重载；Windows共享清单读锁机制保持。

当前completion_scope模式在同一次collect中处理退出但未bind的worker时，bind与record共用临时completion_scope：首次完整解析，后次重新核对执行/封存文件实际SHA及文件身份、attempt/dispatch/模型/上下文和进程退出后复用解析结果。离开本次作用域即清除，变更或重新封存不能命中；独立收取/重启仍重新完整解析。不得扩大成mtime缓存或接受worker自报通过。其余收稿、改稿独立重验、立即交付和故障隔离边界不变。

reserve先按状态和公平顺序排列候选，再校验到首个可派案即停止，同一事务不再重复验证已选案。显式plan仍输出全部阻断；bind、record、deliver各自的完整性边界继续保留。正常CLI收稿以record作为完整执行证据和业务门禁，不在调用前再做一轮相同的全量日志校验；恢复时bind仍需单独确认派发身份。

bind成功直接用返回attempt，后续record仍独立重新加载核验，交付后发布状态读回保留。同一空闲轮只加载验证一次manifest供collect及status读取；状态变更、异常和交付后立即重载，下一轮重新验证。

首次收稿完整解码PDF及全部PNG，主控把本案/本轮/稿件、render引用和校验器身份封存在受回执哈希约束的render_validation；忽略worker自报该字段并实际验证。普通发布仅在主控绑定匹配时省重复解码，仍核稿件、PDF、各PNG、render.json字节、路径和页序。无绑定完整查，错误绑定拒绝；闭批历史审计、池恢复及发布中断恢复均完整解码，真实全页视觉审查不省。

新增成稿在原子发布前完整核验一次，原始来源由该次最终检查负责，不在同一事务提前重复扫描；收稿时的来源核对及发布前复制字节检查保留。旧成稿每次仍核目录归属、身份和SHA，不逐件重扫历史来源/页面/回执；批次收尾和中断恢复完整审计。来源变化保留证据隔离本案，其余合格稿继续。仅明确CaseReceiptError按案拒收且不自动付费重跑；身份/哈希/跨案或未知异常停止新派发。

长准备、收稿和发布I/O由现有独立通道完成，仅以短事务合并共享清单。通过一案即交付，accepted不阻塞其他池补位；先发布新稿再闭批历史审计。详见[三池执行](three-stage-pools.md)，不再增加协调层。

三池调度按既有本地事件和轮询观察进程/文件状态，不发模型轮询请求；当前轮先排除正在prepare/collect的attempt及已隔离attempt，再观察剩余活动任务，外部worker仍保留。独立status默认完整，等待与退出仍检查在途任务，下一轮重新核验；不增加跨轮状态缓存。

池重启时已交付历史完整核验一次，之后才允许新付费派发；若审计失败，记录具体原因并停止新派发和自动交付，仍接收已在运行的worker结果。末案以failed/needs_input结束也执行批次收尾核验，不依赖有新accepted案。回执局部字段错误延迟到全部已提供路径及可核哈希/身份检查之后分类，不能用缺字段掩盖跨案或错误哈希。

## 环境、恢复与验证

runtime.json声明的font_files及Windows字体替代配置共同进入渲染复用指纹；缺失明确失败，不静默替代，身份匹配仍不证明显示正确。环境每批预检一次，首次生成、模板/环境改变时看代表页；普通案件只做本案必要检查，不跑维护回归、查GitHub或重读历史语料。

恢复保留原冻结工具、规则及该批既有复用策略；无对应冻结或覆盖证据的旧批次不得补造新模式或继承通过。新版仅影响新批次。已定位工具缺陷按[故障接续](tool-fault-recovery.md)在维护副本修复验证，保留原证据并继续原授权任务，不新增逐案审批。不得修改有效初稿来迁就故障，也不终止其他案件或共享宿主。

维护按实际改动选测并去重，覆盖规则原文/例外、未知规则、身份/篡改、真实路由、旧版兼容及相关生成错误；不把维护测试放进生产流程。只报告测得的文字量、读取次数或工具耗时，不能等同整批耗时或合格率改善。

## 速度统计

十件新终稿/小时是目标，批次结束或用户要求测速时才运行：

```text
python scripts/batch_throughput.py --manifest 批次manifest.json
```

复用已有CLI事件、起止记录及当前交付DOCX哈希，按案去重并核控制器六项通过，不重新运行验收。计时从pool_started到事件末尾，不含启动前整理；只有完整60分钟窗口和本次开始后实际初稿时标才可报告新稿产能。恢复、预先写好或缺起草时标仅报告交付数，短窗口不外推；不新增逐案统计、台账或门禁，也不因配置容量或合成测试宣称达标。
